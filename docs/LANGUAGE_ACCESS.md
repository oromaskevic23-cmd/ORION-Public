# ORION — Language Selection

**English is the sole authoring language for this GitHub repository.** The README, engineering records, security disclosures, and license documentation are not silently translated or overwritten.

### Language boundaries

1. Keep source code, README text, technical specifications, architecture decisions, and license terms on GitHub in English.
2. Keep non-English presentations and their language picker **on the public websites**, outside the GitHub README.
3. Do not interpret a translated web presentation as a separately executed license or authoritative amendment to the repository's LICENSE.
4. Website availability, actual supported language list, and translation fidelity require independent website checks; the GitHub repository alone cannot certify them.
5. GitHub's own browser/UI language is controlled by GitHub and is separate from language selection for IMPERIAL Core websites.

**Build software. Verify everything.**
